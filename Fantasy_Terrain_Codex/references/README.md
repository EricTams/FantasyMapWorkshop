# Later visual references

Copy this entire `references` folder into the `Fantasy_Terrain_Codex` source folder, beside its README and AGENTS.md. Then run `python verify_package.py --require-references` from that folder.

All five PNGs are preserved unchanged:

- World_20_Clean_Native.png: full map, no grid
- World_20_Dashed_Native.png: full map with dashed grid aid
- World_20_Resource_Key.png: resource/cell coordinate aid
- Terrain_Families_Revision11.png: four-by-four family matrix
- Mixed_Terrain_Revision19_2x.png: mixed-biome transition reference

Their editable source is missing. They are visual targets for a future reconstruction and are not accepted final art. They do not run or reproduce themselves. The accompanying source package contains the older, runnable Prototype55 baseline and the design/continuation brief.
